## 2. Method

1. **Code-Region Pointer Anchors:** We start from all 5,802 differing data-region pointer pairs (`0x08120000`–`0x087FFFFF`, including bit-31-flagged `0x88xxxxxx` compressed asset pointers) catalogued in `dc4-version-differences.md` §4.5, plus all equal data-region pointers (`delta = 0`, `0x08212700`–`0x0849C7B0`) from the code region.
2. **Filtering Non-Shift Pointers:** Removing the 9 coincidental `incrom` constant sequences, the 1 cross-region save pointer (`0x08006334`), the 21 palette-row selector pointers (`0x0802F7D8`–`0x0802F968`) that index different 32-byte rows inside an identical `-0x50C` palette table, and the 1 relocated 80-byte LZ77 block (`RS 0x086E3CFC` → `BM 0x086E3D00`, handled as its own explicit range) yields **3,800 strictly monotonic anchor pairs** `(rs_target, bm_target)`.
3. **Exact Asset Boundary Parsing Across Delta Transitions:**
   - **Single LZ77 assets (`0x10` header):** Decompressing the LZ77 bitstream (and 4-byte zero padding) gives the exact compressed byte length in both ROMs, resolving 17 delta transitions to the exact byte.
   - **Map tileset containers (`0x18`-byte header + 2 consecutive LZ77 blocks):** Parsing the `0x18`-byte container header and both internal LZ77 bitstreams resolves 26 delta transitions in `0x084E695C`–`0x0858530C`.
   - **Map tilemap containers (`0x0C`-byte header + 1 LZ77 block):** Parsing the `0x0C`-byte header and the following LZ77 bitstream resolves 16 delta transitions in `0x084F0664`–`0x08586B38`.
   - **Title screen & end-of-ROM structures (`0x087F06CC`–`0x08800000`):** Exact LZ77 parsing and sub-block anchoring maps both compressed title-screen tilesets (`0x087F0D0C` vs `0x087F07B4` and `0x087F4938` vs `0x087F4848`), their tilemaps/palettes, and the trailing `0xFF` ROM padding (`0x087F739C`–`0x08800000` in both ROMs).
4. **Sub-dividing Constant-Delta Intervals:** Within every constant-delta span, 4-byte words are compared between `RS[addr]` and `BM[addr + delta]` to separate byte-identical (`same`) runs from modified (`differs`) runs (coalescing `< 64`-byte equal islands inside modified blocks).

### 4.2 Major Version-Specific Asset Groups Identified

- **m4a Song Table & Audio Sequences (`0x08120000`–`0x0820A45C`, delta `+0x14` → `+0x0`):** All audio sample data is identical (`same`), while sequence headers and the song table at `0x0820A42C` (`differs`) contain internal ROM pointers shifted by `+0x14`. A 20-byte (`0x14`) padding reduction at `0x0820A42C`–`0x0820A45C` absorbs the `+0x14` code-region shift so that `0x08212700`–`0x0849C7B0` (2.66 MB of IWRAM code and sprite archives) sits at **`delta = +0x0`**.
- **First Version-Specific Compressed Tilesets (`0x0849C7B0`–`0x084BA168`, delta `+0x0` → `-0x1C` → `-0xC` → `+0x6C` → `+0x78`):** Four LZ77 blocks (`0x0849C7B0`, `0x0849CE9C`, `0x0849D148`, `0x084A85D0`) shift the data region to `+0x6C` and `+0x78`.
