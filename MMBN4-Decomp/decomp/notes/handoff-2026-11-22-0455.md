## Key Decisions & Constraints
- **ARMv4T Thumb Jump Tables:** In ARMv4T Thumb mode, `mov pc, rX` requires bit 0 to be 0 (even address). The target cases are local labels (`_08XXXXXX:`) without `.thumb_func`. GNU as emits their even addresses into the table, preserving exact byte matching.
- **Portable Baserom Symlinks:** `Makefile` target `$(BUILD)/baserom.gba` now points to `../../../roms/bn4_$(VERSION)_us.gba` (depth 3 from `build/<v>/`). This avoids mixing MSYS `/c/` and WSL `/mnt/c/` path formats.
- **Symbol Section Relativity:** ROM symbols in `build/<v>/symbols.inc` use `Start + 0x...` section-relative offsets to allow GNU as to resolve references without external relocations.
