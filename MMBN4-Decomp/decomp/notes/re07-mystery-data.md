# RE-07: Mystery Data Tables (Blue, Purple, Green)

Generated by `decomp/tools/mysterydata.py` from US Red Sun (`bn4_rs_us.gba`) and US Blue Moon (`bn4_bm_us.gba`).
Status: **V** = verified in disassembly and both US ROMs.

## 1. Summary & Correction to Earlier Leads

- **Total Mystery Data placements in BN4:** **169** — **109 Blue (BMD)**, **14 Purple (PMD)**, and **46 Green (GMD)**, all in cyberworld map groups (`0x80`–`0x82`, `0x8C`–`0x8E`, `0x90`–`0x94`). The real-world master table (`dat_080ADD18`) has 6 zero slots and a sentinel `1` (no real-world Mystery Data).
- **Flag range correction:** Mystery Data "taken" flags are in **`0x0D00`–`0x10FF`**, **not** `0x15C0`–`0x163F`. Each flag `f` also has a 2-byte state slot in save slot `+0x74` (`[eToolkit+0x74] + (f - 0x0D00) * 2`, `0x800` bytes total): byte `+0` = `placement_idx`, byte `+1` = `content_idx`. Both flags `0x0D00`–`0x10FF` and slot `+0x74` are stashed/restored across New Game+ (`sub_0800143C`/`sub_08001460`), and then `MysteryDataAdvanceAll` (`sub_080ADE5C`) advances taken BMDs/PMDs to their next pickup tier and clears their flags.
- **Advance-on-pickup mechanic (types 1 & 3):** Every BMD (`type 1`) and PMD (`type 3`) in BN4 has **2 or 4 sequential reward slots** (1st pickup, 2nd pickup, [3rd pickup, 4th+ pickup]). On New Game+, `MysteryDataNextIndices` (`sub_080ADEB2`) checks whether `flag` was set on the previous playthrough: **if taken**, `content_idx` increments by 1 (clamped to the last slot) and `flag` is cleared; **if not taken**, `content_idx` stays unchanged so the player cannot permanently miss an earlier tier's reward by skipping it on Normal/Hard. (Types `2` and `4` exist in `sub_080ADEB2` as playthrough-indexed variants, but **0** entries in BN4 use them.)
- **Green Mystery Data (type 5):** Every GMD has **4 spawn coordinates** and **3 playthrough tiers** (Normal / Hard / Super Hard, capped at `min(GetPlaythrough(), 2)`), each with **8 weighted reward entries** (including virus-trapped chips and virus-trapped Zenny). `MysteryDataRollAllGreen` (`sub_080ADDA0`) rerolls every GMD's placement and content and clears its flag on new game and on every jack-in (`sub_080297C8`).
- **RS vs BM differences:** **Zero** differences in the Mystery Data tables (`0x080A9110`–`0x080ADD8C`, 0 non-pointer-shift word diffs between US RS and US BM) and **zero** differences in the Mystery Data pickup script archive (RS `0x087585A0` / BM `0x08758030`, `0xD1C` bytes, byte-identical). The only practical version difference is **reachability of version-exclusive scenario comps** in groups `0x8C`–`0x8E` (e.g., `WtrGodComp1`–`16` for Blue Moon's AquaMan scenario, vs Red Sun-exclusive tournament comps).

### Lifecycle
1. **New Game (`NewGameInit`, `0x080049A8`):** Calls `MysteryDataInitState` (zeroes slot `+0x74`), `MysteryDataAdvanceAll`, and `MysteryDataRollAllGreen`.
2. **New Game+ (`sub_08000DE8`):** Restores flags `0x0D00`–`0x10FF` and slot `+0x74`, increments playthrough, and calls `MysteryDataAdvanceAll` (`sub_080ADE5C`).
3. **Jack-In (`JackIn_ResetGreenMysteryData`, `0x080297C8`):** Calls `MysteryDataRollAllGreen` (`sub_080ADDA0`), rerolling all 46 GMDs via `WeightedRandomIndex` (`sub_08000CA0`: `(GetRNG() & 0x3FF) % sum(weights) + 1`) and clearing their flags.
4. **Map Load (`MapObj_SpawnMysteryData`, `0x080A89BC`):** Map object spawn script passes the 16-bit `flag`; calls `MysteryDataLookupSpawn` (`0x080ADF80`), selects palette from `dat_080A8A50` (`FF 00 00 02 02 01`: Blue=0, Purple=2, Green=1), places object at `(x, y, z)`, and computes pickup script index `(content_kind - 1) * 10 + (type - 1)` in text archive `0x087585A0` (RS) / `0x08758030` (BM).
5. **Pickup (`MapObj_InteractMysteryData`, `0x080A84E8` / `MysteryDataLoadScriptVars`, `0x0809DB10`):** Calls `MysteryDataLookupReward` (`0x080ADFF0`), writes `flag` to `[text_state+0x4C]`, `reward_val` (`u32` at `+4`) to `[text_state+0x54]`, and `param` (`u8` at `+3`) to `[text_state+0x58]`, then executes the pickup text script (which handles Unlocker for PMDs, Untrap/virus battles for trapped GMDs, grants the reward, and sets `flag`).

## 3. Table Layouts (V)

All Mystery Data tables sit in a single contiguous block in `code_06`: RS `0x080A9110`–`0x080ADD8C` (BM `0x080A911C`–`0x080ADD98`, delta `+0xC`, `0x4C7C` bytes).

| Table | RS Address | BM Address | Layout |
|---|---|---|---|
| Real-world master table | `0x080ADD18` | `0x080ADD24` | 6 × `u32` (all `0`) + sentinel `0x00000001` |
| Cyberworld master table | `0x080ADD34` | `0x080ADD40` | 21 × `u32` group pointers (`0x80`–`0x94`, `0` if unused) + sentinel `0x00000001` |
| Per-group map pointer table | `0x080A9110`… | `+0xC` | `0`-terminated array of pointers to per-map entry lists |
| Per-map entry list | `0x080A9110`… | `+0xC` | 12-byte records terminated by `type == 0`: `{u8 type, u8 obj_flags, u16 flag, ptr placements, ptr contents}` |
| Placement list | `0x080A9110`… | `+0xC` | 8-byte records terminated by `valid == 0`: `{u8 valid (1), u8 weight, s16 x, s16 y, s16 z}` (1 entry for BMD/PMD, 4 for GMD) |
| Content list | `0x080A9110`… | `+0xC` | 8-byte records terminated by `kind == 0`: `{u8 kind, u8 weight, u8 pad (0xFF), u8 param, u32 value}`. For GMD (`type 5`), 3 consecutive `0x44`-byte tier blocks (8 × 8-byte entries + 4-byte `0` terminator each). |

## 6. Red Sun vs Blue Moon Differences

- **ROM Mystery Data tables (`0x080A9110`–`0x080ADD8C`):** **0** non-pointer-shift word differences. Every single BMD, PMD, and GMD placement, flag, coordinate, weight, and reward across all tiers is **100% identical** between US Red Sun and US Blue Moon (every internal ROM pointer shifts uniformly by `+0xC`).
- **Pickup text script archive (RS `0x087585A0` / BM `0x08758030`, `0xD1C` bytes):** **Byte-identical** (`True`).
- **Scenario-comp reachability caveat (for Violet Eclipse):** Although the tables are identical in both ROMs, several small comps in groups `0x8C`–`0x8E` belong to version-exclusive tournament scenarios (for example, `WtrGodComp1`–`16` in group `0x8E` belong to Blue Moon's AquaMan scenario, and certain DenDome/Castillo/Colosseum comps belong to specific tournament branches). Making all scenarios playable in Violet Eclipse automatically unlocks their BMDs too.

## 7. Diff Against `ref/maps/legend.csv`

- **Main 32 areas:** **78 / 78** exact matches (`legend.csv` has 78 BMD/PMD rows; ROM has 78 in those 32 areas).
- **Small comps (`0x8C`–`0x8E`):** **45** additional BMDs in the ROM are not listed in `legend.csv` (the fan maps only covered the 32 main net and dungeon areas). Notable unique items among those 45 comp BMDs include `SpinWhit` (`StatueComp`), `SpinPink` (`ColoNBMComp`), `SpinYllw` (`GoddessComp`), `ExpMemry` (`HeroComp`), `SubMemry` (`CastNBMComp` 2nd, `NupopoComp`, `Ticket Comp`), `FullCust *` (`WtrGodComp12`), `HP Memry` (7 comps), `RegUP1`/`RegUP2`, `Fish`, `Battery`, and multiple battle chips.

Zero mismatches in the 32 main areas.
