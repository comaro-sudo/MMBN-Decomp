# docs/

Index of everything in `docs/`, one line each. **Current** = kept up to date and safe to rely on. **Historical** = a record of how or why, no longer maintained. **Open** = waits for an owner decision. Updated 2026-11-27.

The plan is in [`../plan/`](../plan/README.md) (the goal: [`DEFINITIVE-EDITION.md`](../plan/DEFINITIVE-EDITION.md)). The patch packages and their test status are in [`../patch/README.md`](../patch/README.md). Third-party guides and maps used as references live in `../ref/` (local only). Test evidence is Gemini's, in `../decomp/notes/` (for example `patch-test-results-7-c1-c5.md`).
