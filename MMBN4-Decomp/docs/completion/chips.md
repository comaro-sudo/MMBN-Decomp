# Chips (criterion C2)

Generated by `patch/tools/inventory.py` (see [method.md](method.md)). Ids are chip ids (`0x000`–`0x184`). "Library number" is the record's `+0x1C` field: standard 1–150, secret 151–186, Mega 200+, Giga 280+, PA 300+.

## 1. The chip table is the same in both versions

All 389 records (`0x080197EC`, `0x2C` bytes each) are byte-identical between Red Sun and Blue Moon. So the merged ROM doesn't need the other version's chip *data*. It needs the other version's **sources**: battles, drops and traders. For Navi chips, it also needs the Navi's **battle**, whose AI and graphics are version data (DC-4).

They come from beating the Navi's V2, V3 and SP versions, from an S rank against SP, and from the DS version in Black Earth 2. In the original game, a traded copy shows up in the other version's Library as a secret chip.

**Owner decision (2026-11-23) for the three special chips:**
- **Duo:** a **reward for beating Duo at his highest tier** (V3/Ω, or in a post-game rematch). The same kind of hook as the Bass patch (WP-D3): grant the chip after that battle.
- **Z-Saver and Grand Prix Power (owner, 2026-11-23; replaces the shop plan below): two Blue Mystery Data in an out-of-the-way corner** of a net area, one holding Z-Saver `Z` and one Grand Prix Power `G`.
  - Why: the shop route needed a code hook with no free code space nearby, plus a load hook for old saves.
  - How (RE-07, `decomp/notes/re07-mystery-data.md`):
    - two new placements in the chosen area's Mystery Data list, using free "taken" flags in `0x0D00`–`0x10FF` (169 of 1,024 are used);
    - each with every content slot set to its chip, so New Game+ advancing it changes nothing;
    - plus the area's spawn script entry.
    - Blue, so no Unlocker is needed.
  - **Placement (owner, 2026-11-23): one in an Undernet dead end, one in a quiet corner of an early area (ACDC).**
    - Split (owner confirmed, 2026-11-23): **Z-Saver in the Undernet** (a rare sword for a hidden, dangerous place) and **Grand Prix Power in ACDC** (an early surprise).
    - The exact spots, a dead end off the main path in each area, come from the maps (`ref/maps/`, local) and the areas' Mystery Data coordinates (RE-07).
- *(Superseded: Z-Saver and Grand Prix Power sold at Higsby's shop at a very high price. Kept for the record.)*
  - Higsby's regular stock (shop record 4) is full: 8 of 8 slots, in a fixed 0x40-byte block of the save (`../re/shops.md`). So the proposed place is **Higsby's chip-order list (record 16)**: 320 slots, about 266 used, so its ROM init table has free slots.
  - **They always appear** in the list (owner, 2026-11-23), whether or not they're in the Library.
  - **Findings (Claude, 2026-11-23, V):**
    - **Chip ids:** Z-Saver = `0x0DA` (218), code `Z` only, Library number 280. Grand Prix Power = `0x138` (312, named `PrixPowr`), code `G` only, Library number 291. Both are Mega chips (`ext/mmbn-chip-tables`, `build/inventory/chips.csv`).
    - **The chip-order list does hide chips that aren't in the Library:**
      - `ShopBuildChipOrderList` (`0x0804BD18`) puts each entry in list A (`0x0201A000`) when none of its flags `0x16C0` / `0x18C0` / `0x1AC0` + id is set, and in list B (`0x0201B400`) when one is;
      - the shop screen's chip-order branch (`sub_0804ABBC`, `_0804AC50`) **reads only list B**;
      - its per-entry filter `sub_0804ACBC` is a stub that never skips.
    - The builder **stops at the first empty slot** (type 0), so new entries must follow the last chip entry of record 16 in `BN4_SHOP_STOCK_INIT`.
  - **What the patch needs:**
    1. Two new stock entries right after record 16's last chip: `{type 2, qty 1, id, code, 0, price 4500}`.
    2. Make the builder file these two ids under list B even without a flag. A small hook on the builder's flag test (`bl TestEventFlag` for `0x18C0 + id`) returns "set" for ids 218 and 312.
       - It must use the "not owned" path (`+5` flag = 1) and the index `Library number × 8`.
       - The hook needs a **code cave within `bl` range** of `0x0804BD9x`. Both dead blocks in `code_03` are already used, so another one must be found: unused code in `code_03`, or a `bx`-register trampoline.
    3. For existing saves: shop stock is copied at new game, so a load hook would have to add the two entries to the save's shop block.
  - **Price: 450,000 Zenny each** (owner, 2026-11-23): the price field value 4500 (× 100).
  - Caveat: shop stock is copied into the save at new game, so existing saves only get them if a load-time hook adds them.

## 4. To check against the ROM

- **Codes with no listed source:** WideSht3 U, Vulcan3 T, TwnFng3 H, MokoRus2 U, DublCrak B/L/R, TripCrak B/L/R. The record has the code, but the reference gives no source. They may come from Green Mystery Data or virus drops the guide missed, so check them against the ROM's GMD and drop tables.
- **LongSwrd and FstGauge:** not matched to the guide by name or number. The maps list LongSwrd from Blue Mystery Data (Electric Tower 2) and FstGauge in an Undernet 1 shop.
- **MetlGer3, BurnMnDS, FinalGun:** no source listed anywhere. FinalGun has two records (`0x122` Giga and `0x182`) and may be a cut chip.
- **Dark chips `0x0C3` and `0x0C4`:** no name and no codes; probably unused.

## 5. Not collectibles

- **30 Program Advances:** combinations of chips the player already has. A PA is counted once it has been used (the Library flag table at `0x0801F508`, written by `sub_0801F4E4`: see [`../re/save-and-flags.md`](../re/save-and-flags.md)).
- **57 internal records:** Soul charge attacks (FirePlus, ThunPlus, AquaPowr, WoodPowr, BlakWeap), MegaMan's modes (CannMode, SwrdMode, Marking), the Soul and Dark forms, debug entries (FastFwd, Rewind, Training) and empty records.
