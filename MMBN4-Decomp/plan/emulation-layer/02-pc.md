# 02 — PC (Windows ARM64, x64)

**Layer:** mGBA 0.10.5 core, static, GBA only. **Status:** PC-1 done ([../10-pc-port.md](../10-pc-port.md)). The PC is the **reference frontend**: everything in `ports/common` is developed and tested here first.

| Area | Plan |
|---|---|
| Performance | About 11% of one core measured. No concerns. Add `--bench` for the cross-port comparison table |
| Video | SDL3 + D3D11, integer scale. Add an option for the mGBA layer-tag output so the 3DS depth logic can be prototyped on PC (render a red/cyan anaglyph or side-by-side for checking) |
| PET | Second window = `PET_WIDE` layout (854×480 logical), mouse and touch, the reference for the Wii U GamePad |
| "Off-TV" equivalent | Single-window mode: game plus a compact PET side panel (the Wii U Off-TV layout, tested here) |
| Input | Keyboard + XInput/SDL gamepads. Remapping (PC-6) |
| Builds | ARM64 (native) and x64 from `build_pc.py --arch` |
| Linux / Steam Deck / Android | **Optional extras:** the same SDL3 frontend builds there. Android matters only if the Retroid (from the Silent Hill project) becomes a target. Not committed |

Milestones (from plan/10): PC-2 hooks, PC-3 PET v1, PC-4 touch Custom Screen, PC-5 Net Map, PC-6 settings and packaging. Each lands in `ports/common` and reaches the consoles from there.
