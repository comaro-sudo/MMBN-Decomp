# 04 — Nintendo 3DS

**Layer:** mGBA 0.10.5 core (mGBA has an official 3DS platform). **Target: New 3DS / New 2DS XL.** Cyberworld Endless measured the mGBA core at **11 of 16.7 ms per frame** on the New 3DS (804 MHz, L2 cache) with an idle hook, and found that on the **Old 3DS/2DS (268 MHz) the core alone takes longer than a frame**. BN4 runs on the same engine family as the BN6 they measured, so expect similar numbers. Confirm with `--bench`.

## Hardware mapping

| Area | Plan |
|---|---|
| Toolchain | devkitARM + libctru + citro2d/citro3d (`dkp-pacman -S 3ds-dev` in WSL aarch64; **not installed yet**) |
| Core | libmgba built with devkitARM (mGBA's `src/platform/3ds` shows the platform specifics: `ctru-heap`, linear memory, `FIXED_ROM_BUFFER`) |
| CPU | Core on the **third CPU core** (New 3DS, `APT_SetAppCpuTimeLimit`, a core thread as in Cyberworld Endless's `thread.md`). Director and PET on the main core. Clock at 804 MHz + L2 (`osSetSpeedupEnable`) |
| Memory | 124 MB app memory on the New 3DS. ROM 8 MB + mGBA's buffers fit easily (Cyberworld Endless budgets 96 MB heap) |
| **Top screen 400×240** | Game at 1× centred (240×160, crisp) with bezel art, or 1.5× (360×240) with sharp-bilinear. Player option |
| **Stereo 3D** | Per-pixel layer tags from mGBA's renderer → depth classes (background behind, map tilted, standing sprites upright, HUD at the screen), the approach in Cyberworld Endless's `stereo.md`. Each eye's image composed with horizontal shifts in citro3d. The slider sets the depth. Prototype the classification on PC first (02) |
| Widescreen 400 px | **Out of scope for the emulation layer:** the game draws 240 px. Needs decompiled camera code (decomp C5 priority 5) |
| **Bottom screen 320×240** | `PET_QVGA` layout with touch (resistive; tap and drag, no multi-touch) |
| Audio | ndsp, 32 kHz s16 stereo from blip |
| Input | D-pad and Circle Pad (snapped to 4-way in battle), ZL/ZR (New 3DS) hotkeys: Full Synchro / quick SubChip |
| Saves | `sdmc:/3ds/mmbn4/<code>.sav` (mGBA format, shared with PC/Wii U) |
| Packaging | `.3dsx` (Homebrew Launcher). `.cia` optional |

## Old 3DS (optional spike, gate G-O3DS)

- Only a **dynarec** core could fit: libretro **gpSP** has an ARM dynarec for ARMv6+ (the 3DS's ARM11 is ARMv6K), and Cyberworld Endless measured gpSP about 3.5× faster than mGBA on the PSP.
- Costs:
  - a second backend (no mGBA layer tags, so no depth, and different state and hook handling);
  - **GPL-2.0** (would set the licence of that build);
  - less accuracy.
- Do it only if the benchmark shows it fits *and* Old 3DS support matters to you.
