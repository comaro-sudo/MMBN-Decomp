# Mega Man Battle Network 1: decomp (planned)

Status: **plan only** (2026-11-27). No code, no ROM, no tools. The collection's order is BN4 first, then BN1 ([AGENTS.md](../AGENTS.md) §0). Nothing here starts until the owner says so.

This folder will hold the BN1 (*Battle Network* / *Rockman EXE*, GBA, 2001) byte-matching disassembly, notes and plans, built from the player's own ROM, with the same rules as BN4: no ROM bytes in git, everything opaque is `.incbin`'d from `roms/` at build time, and `roms/`, `tools/`, `ext/` and `build/` are gitignored.
