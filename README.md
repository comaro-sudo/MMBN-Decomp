# MMBN4 Overhaul

A gameplay overhaul of Mega Man Battle Network 4 (Red Sun / Blue Moon), distributed as patches, with later ports to PC, NDS and 3DS. Solo project.

| Folder | Contents |
|---|---|
| `plan/` | Project plan. Start at [plan/README.md](plan/README.md) |
| `docs/` | Design document, reference repo list, hardware profile, RE notes (`docs/re/`) |
| `roms/` | Your own ROM dumps (gitignored, see [roms/README.md](roms/README.md)) |
| `src/common/` | Version-agnostic armips sources |
| `src/bm/`, `src/rs/` | Blue Moon / Red Sun offsets and defines |
| `src/scripts/` | Edited TextPet scripts |
| `src/data/` | Chip, encounter and shop tables |
| `test/saves/`, `test/lua/` | Test save library and mGBA Lua automation |
| `tools/`, `ext/` | Third-party tools and cloned reference repos (gitignored) |
| `build/` | Patched ROMs and `.bps` output (gitignored) |
